# Phase 03 Plan 02: Streamline Order Creation

## Phase Goal

**As a** cassette store operator, **I want to** create an order directly from `/order/create`, **so that** I can move from customer lookup to saved order without bouncing through the order list modal.

<objective>
Move customer lookup and inline customer creation into the order create route, compress the order form around core daily fields, and preserve all existing order creation calculations and Phase 2 sync-result handling.
</objective>

<context>
Read Phase 3 CONTEXT decisions D-01 through D-12 and D-17 through D-18. Current source facts: `OrderListScreen` opens a customer-search modal and navigates to create with `location.state.customerId`; `OrderCreateScreen` only renders when it can resolve that route-state customer ID. Existing `CustomerSearchWidget`, `CustomerAddWidget`, and `OrderCreateScreen` should be composed or lightly extended rather than duplicated.
</context>
