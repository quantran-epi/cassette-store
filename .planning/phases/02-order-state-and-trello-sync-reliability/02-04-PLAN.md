## Phase Goal

**As a** cassette-store operator, **I want to** see and retry failed Trello sync actions from the affected order, **so that** I can recover without manually editing app state.

<objective>
Add compact hands-on retry/recovery controls for persisted order sync failures and close Phase 2 with regression coverage.

Purpose: Plans 01-03 make domain rules testable, Trello calls structured, and partial failures durable. This plan satisfies `SYNC-03` by exposing those failures to the operator at the order surface with action-specific retry.

Output: Per-order sync status widget, retry orchestration, manual resolved escape hatch, and final regression/build verification.
</objective>
