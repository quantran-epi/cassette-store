## Phase Goal

**As a** cassette-store operator, **I want to** know which Trello operation failed, **so that** failed sync work can be retried without guessing.

<objective>
Create the typed Trello/order integration adapter and operation-result types required before `useOrder` orchestration is refactored.

Purpose: Existing Trello calls return raw values and inconsistent failures. This plan satisfies `SYNC-01`, `ORD-03`, D-03, D-19, D-20, and D-23 by introducing a small adapter/result layer over existing Trello endpoints and making HTTP failure handling reliable.

Output: Shared operation-result types, a tested order-specific Trello adapter, and safer `useAPI` URL/error behavior.
</objective>
