## Phase Goal

**As a** cassette-store operator, **I want to** keep my local order work even when Trello fails, **so that** I can recover sync without losing the business action.

<objective>
Refactor `useOrder` order workflows to use pure transitions and the Trello adapter while persisting retryable sync failures.

Purpose: This plan delivers the core reliability behavior from `SYNC-02` and prepares `SYNC-03` by making local/Trello ordering explicit, durable, and test-covered.

Output: Persisted sync-failure state, workflow result types, restored backup defaults, and local-first `useOrder` orchestration for create order, update order, shipping code, shipped/returned states, and attachments.
</objective>
