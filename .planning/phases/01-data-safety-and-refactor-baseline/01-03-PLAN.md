<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote backup URL to browser restore flow | Fetched text is untrusted until normalized. |
| Browser local state to Trello attachment | Current Redux state is serialized and uploaded to the configured Trello card. |
| Normalized restore payload to Redux dispatch | Validated payload crosses into persistent IndexedDB-backed Redux state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03-01 | Tampering | `_onRehydrateData` | mitigate | Parse and normalize the entire backup before any dispatch; invalid input causes no mutation. |
| T-01-03-02 | Denial of Service | Restore fetch/parse | mitigate | Catch network and JSON errors, clear loading state in `finally`, and show actionable error messages. |
| T-01-03-03 | Repudiation | Pre-restore mutation | mitigate | Create or offer a current-state recovery snapshot before applying restored state. |
| T-01-03-04 | Information Disclosure | Trello backup attachment | accept | Existing trusted internal Trello backup model is preserved per D-05; no broader provider is introduced. |
</threat_model>
