## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backup JSON to normalizer | Untrusted text or object crosses into restore validation. |
| Normalized backup payload to Redux reducers | Only validated data should become persisted app state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-01 | Tampering | `BackupHelper.normalizeBackup` | mitigate | Validate top-level schema, required sections, and defaults before returning success. |
| T-01-02-02 | Denial of Service | `parseBackupText` | mitigate | Reject empty input and invalid JSON with error result instead of throwing into UI flow. |
| T-01-02-03 | Repudiation | Restore errors | mitigate | Return distinct error codes/messages for unsupported schema, missing sections, invalid JSON, and empty backup per D-10. |
</threat_model>
