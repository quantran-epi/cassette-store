# Phase 05 Plan 02: Mobile-Native Daily Workflow Layouts

## Phase Goal

**As a** mobile cassette store operator, **I want to** scan and act on order, customer, and order-create screens with dense tappable cards, **so that** daily work is faster without losing the Phase 1-4 workflow behavior.

<objective>
Refresh the highest-use mobile workflow surfaces into compact tokenized list/form layouts: order list filters and rows, order item metadata, customer list rows, and the order-create form. This plan is presentation-first and preserves selector wiring, URL query behavior, order/customer handlers, and create-order calculations.

Purpose: Deliver UX-02 mobile density/readability while guarding UX-05 behavior preservation before copy/state standardization and dashboard reorganization.
Output: token-consuming mobile list/form layouts with focused RTL coverage for order list, customer list, and order creation.
</objective>
