# Phase 05 Plan 04: Decision-Oriented Mobile Dashboard

## Phase Goal

**As a** mobile cassette store operator, **I want to** see dashboard metrics grouped by the operational decisions they inform, **so that** I can decide what to reconcile, follow up, ship, or review without scanning raw totals.

<objective>
Rework the dashboard presentation around operational decision groups while preserving Phase 4 selector-backed formulas. Extend selector read models only when the dashboard needs a named grouping value, and keep all order/customer reductions out of the React view.

Purpose: Deliver UX-04 with UX-05 behavior preservation and bring dashboard presentation into the Phase 5 visual system.
Output: selector-backed decision groups, a mobile card/list dashboard screen, and focused tests proving values are derived from `buildDashboardReadModel` rather than recomputed in the view.
</objective>
