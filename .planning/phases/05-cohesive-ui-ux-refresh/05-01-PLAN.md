# Phase 05 Plan 01: Token-Driven Visual System Foundation

## Phase Goal

**As a** mobile cassette store operator, **I want to** use screens that share a compact, readable visual system, **so that** repeated order, customer, COD, and dashboard work feels consistent without changing verified business behavior.

<objective>
Replace the inline Ant Design theme and local magic numbers with a token-driven visual system, then add the shared tap-reveal primitive that later mobile list/form plans can use for long customer names, addresses, notes, and shipping codes.

Purpose: Establish UX-01/UX-02/UX-03 foundations before any screen rebuild so later plans consume the same spacing, typography, color, radius, shadow, and reveal contracts.
Output: `src/theme/tokens.ts`, `src/theme/buildAppTheme.ts`, tokenized root theme wiring, tokenized `Card`, and `TruncatedText` exported from the Typography component package.
</objective>
